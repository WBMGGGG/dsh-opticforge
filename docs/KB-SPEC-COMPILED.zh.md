# 编译型板块写作规范（F/G/H 系列）

原有 A–E 板块有厂商原文快照 `_kb-raw/`，改写时数字逐字回查。新增板块没有原文可存，来源是**公开教材、标准与综述的通用结论**，因此规则要收紧一层：只写能追溯到标准教材的结论，不写具体产品型号与厂商实测值。

## 一、字段契约（与原有板块完全一致，9 项）

```json
{
  "doc_id": "F01",
  "chunk_id": "F01-01",
  "status": "present",
  "is_original_excerpt": false,
  "text": "【标题】\n定义：…\n公式：…\n判据：…\n边界：…",
  "source": "公开教材综合：Hecht《Optics》5e；Born & Wolf《Principles of Optics》7e；郁道银《工程光学》",
  "page_or_section": "综合：几何光学 / 成像公式",
  "keywords_zh": "薄透镜,成像公式,牛顿公式,放大率,符号约定",
  "disclaimer": "本条为教材通用结论的工程整理，非原文摘录；公式符号约定与推导以所列来源为准。"
}
```

- `source` 必须是**真实存在的公开来源**：教材（作者 + 书名 + 版次）、标准（编号 + 名称）、综述（期刊 + 年份）。不许写「某某手册」这种无法核对的模糊来源。
- `page_or_section` 写主题位置，不写具体页码（编译型条目不对应单一页）。
- `disclaimer` 固定说明「非原文摘录」。

## 二、正文写法

- 以 `【标题】` 开头（≤ 24 字），之后每行一个字段：`定义：` / `公式：` / `判据：` / `边界：` / `工程要点：` / `误差来源：`，按主题取用，不必凑满。
- **长度下限 300 字**（编译型条目要比原文摘录更完整，不允许一句结论敷衍），不设上限。
- 数值只允许三类：
  1. 公式常数（1.22、0.61、2π、√2 等）；
  2. 物理常数（c、h、k_B 等）；
  3. 标准定义值（如 ISO 25178 的 Sa 定义、CIE 1931 色匹配函数波长范围 380–780 nm）。
  
  **禁止**写具体产品指标（某型号量程、某厂商分辨率、某镜头 MTF 数值）。那类内容只在 A–E 板块里有原文依据。
- 不写营销词（领先/优异/最佳/完美/low cost/high performance）。
- 不写「据说」「业内普遍认为」这类不可追溯的措辞；不确定的就不写。

## 三、质量判据（校验器强制）

| 项 | 要求 |
|---|---|
| 字段 | 9 项齐全、`doc_id` 与文件名一致 |
| 状态 | `present`、`is_original_excerpt=false` |
| 正文 | 以`【`开头、≥300 字、含至少 3 个字段行 |
| 数字 | 编译型不做逐字回查（无原文层），但禁止产品指标 |
| 术语 | `keywords_zh` 用逗号分隔、≥4 个、与正文同语言 |

## 四、板块与条目清单

见 `docs/KB-OUTLINE.zh.md`。**chunk_id 必须按清单里的编号顺序生成**，不得自行增删或改名——校验器按清单核对条目集合。

## 五、写作口径

读者是有工程经验的光电工程师，不是学生。每条要能回答「这条在什么条件下成立、什么时候会失效、现场踩什么坑」，而不是复述教科书目录。

反例（不合格）：

> 【衍射极限】
> 定义：光学系统分辨率受衍射限制。公式：d=1.22λ/NA。判据：看 NA 大小。

正例：

> 【衍射极限与艾里斑】
> 定义：孔径受限的成像系统，其点扩散函数为艾里斑，第一暗环半径决定两点可分辨的下限。
> 公式：艾里斑半径 r=0.61λ/NA；第一暗环直径 d=1.22λ/NA。
> 判据：瑞利判据取两点间距等于艾里斑半径时「刚好可分辨」；工程验收常取 d 作为保守值。
> 边界：仅适用于无像差的圆形光瞳、相干照明近似；存在像差、中心遮拦或部分相干照明时，实际分辨率低于该式。
> 工程要点：NA 提升受工作距离与景深约束；浸液/固体浸没可把 NA 推到 1 以上。
